# Ритм консультаций

HTML-дашборд для Больницы имени В. В. Вересаева.

## Быстрый запуск

Нужны Python 3.10+ и библиотеки существующего проекта:
    python -m pip install -r requirements-dashboard.txt

Окно выбора Excel и сохранения HTML:
    python zhk_dashboard.py

Запуск без параметров открывает окно: выберите Excel, проверьте период и нажмите «Создать HTML-дашборд». После выбора места сохранения отчёт собирается и открывается в браузере. Флаг --gui также поддерживается. При запуске с параметрами остаётся автоматический режим.

Автоматическое обновление:

1. Положите полную выгрузку месяца в папку incoming рядом с zhk_dashboard.py.
2. Запустите update_dashboard.sh (Linux) или update_dashboard.bat (Windows).
3. Откройте dashboards/dashboard_ДАТА_ДАТА.html в браузере.

Берётся только ОДИН самый новый по времени изменения файл. Накопительные выгрузки не складываются друг с другом. Для одинакового периода скрипт обновления заменяет ранее созданный HTML. Если не хотите заменять, используйте Python-команду без --overwrite.

## Годовой план: ручной ввод

1. Запустите `python zhk_dashboard.py` и нажмите **«Годовой план…»**.
2. Укажите дату отчёта и четыре числа для каждой консультации: план года, факт с 1 января до начала месяца, план полного месяца, факт текущего месяца по дату отчёта.
3. Нажмите **«Сохранить годовой план»**, затем создайте HTML из выгрузки услуг. Проценты и тренд пересчитываются автоматически.

Показатели со скриншота на 22.10.2026 уже заполнены. Общий план месяца указан отдельно как в источнике: 12 085; сумма строк — 12 086. Если оставить общий план месяца пустым, программа сложит подразделения. Расхождение явно отмечается в отчёте.

План сохраняется в `annual_plan.json` рядом с программой. Отдельный Excel или обработка PDF не нужны. При каждом сохранении предыдущая версия остаётся в `annual_plan.backup.json`. Неверные значения не заменяют файл.

На вкладке «Репродуктивное здоровье» нажмите **«Раскрыть план»**. Слева общая годовая шкала, справа четыре консультации; нажатие на консультацию меняет показатели шкалы. Фильтры месячных услуг не меняют этот отдельный отчёт, дата плана всегда видна. Блок отсутствует на вкладке «Все услуги».

**69,9% — выполнение плана, ожидаемого к 22 октября. 56,6% — доля полного годового плана.** На единой шкале факт 56,6% сравнивается с ожидаемой долей 80,9%. Годовой план разделён на 12 равных месяцев, текущий месяц учитывается пропорционально календарным дням. Тренд — разница неокруглённых процентов выполнения к началу месяца и на дату отчёта. Данные годового отчёта измеряются в женщинах; их нельзя складывать с количеством услуг Excel.

Можно снять флажок «Добавить годовой план» при сборке. Сохранённые HTML не меняются после редактирования: сформируйте новый отчёт. Дата плана не обновляется автоматически вместе с датой Excel — внесите новый факт и новую дату вручную.

Команды:

```bash
python zhk_dashboard.py --edit-plan
python zhk_dashboard.py --input services.xlsx --annual-plan annual_plan.json
python zhk_dashboard.py --input services.xlsx --without-annual-plan
```

## Явный запуск

    python zhk_dashboard.py --input "/путь/услуги.xlsx" --date-to 23.10.2026 --output dashboard.html

По умолчанию период: с 1-го числа текущего месяца по текущую дату, московское время.
Для исторических данных укажите --date-to. Начало этого месяца подставится автоматически.
Для другого интервала добавьте --date-from 01.10.2026.

Дополнительно:

- --overwrite: заменить существующий HTML.
- --sheet "Лист1": выбрать лист, если в книге несколько подходящих таблиц.
- --all-departments: включить подразделения за пределами женских консультаций.
- --no-restore-missing: запрещает восстановление пустого тарифа.
- --input-dir "/путь/к/папке": изменить папку входящих файлов.

Пустой или некорректный исходник не заменяет предыдущий HTML. Отрицательные и дробные количества отклоняются с номером строки. Исправьте исходную выгрузку и повторите запуск.

## Расчёты

**Подтверждено владельцем выгрузки: тариф — цена ОДНОЙ услуги.**
Количество = сумма «Кол-во».
Сумма строки = Тариф × Кол-во, округление HALF_UP до двух знаков; итог = сумма округлённых строк.
В браузере суммы хранятся целыми копейками.
Две одинаковые строки не удаляются: они могут означать разные выполненные услуги.

Пустой тариф восстанавливается только при одной положительной цене того же кода в том же месяце среди включённых строк. Количество при восстановлении не влияет на цену-донора. При нескольких ценах генерация останавливается. Явно нулевой тариф не заменяется. Число восстановлений и нулевых тарифов показано в «Как считаем».

## Сигналы снижений

Порог по умолчанию: более 40%, в отчёте можно выбрать 25% или 50%.
Для даты сравниваются до четырёх предыдущих таких же дней недели внутри выбранного периода.
Нужны минимум два предыдущих дня с любыми услугами врача.
База — медиана количества или суммы выбранных услуг в эти дни.
Текущий день и дни без какой-либо активности врача не дают сигналов.
Сигнал появляется при снижении количества ИЛИ суммы; отображается более сильное снижение.

Это описательная статистика, а не план, оценка эффективности врача или медицинская рекомендация.
Расписание смен, отпуска, пропуски выгрузки и причины снижения не известны.
Точка в календаре означает отсутствие сведений об активности; ноль означает отсутствие выбранной услуги при наличии других услуг.
Внутри периода выгрузки линия графика проходит через ноль в дни без услуг, включая начало и конец выбранного периода. Это означает отсутствие услуг в выгрузке, а не подтверждение рабочего дня; расчёт медианы и сигналов не изменён.
Между последней датой выгрузки и концом периода нули не подставляются.
Среднее по дням недели делится на дни с любыми услугами в текущем выборе, а главный средний показатель — на дни с выбранными услугами; подписи показывают различие.

## Защита и качество данных

ФИО пациентов, даты рождения, полисы, диагнозы и ID пациентов в HTML не попадают.
В отчёте остаются ФИО врачей и производственные показатели. HTML содержит все включённые агрегаты:
фильтр врача — удобство просмотра, не разграничение доступа.
При распространении отдельным врачам учитывайте это свойство статического HTML.

Выгрузка читается без изменения. В итоговых метаданных сохранены имя файла, лист, SHA-256 и статистика.
Текст экранируется для HTML/JavaScript. CSV защищён от формул в текстовых полях.
Для сохранения ведущих нулей код в CSV снабжён текстовым префиксом; при импорте в Excel задайте тип колонки «Текст».

## Дневной план по ЖК

Раскройте «Годовой план ДОРЗ». У каждой консультации видны её план месяца, дневной ориентир, выполнено и остаток за выбранную дату. Нажмите консультацию: ниже появится подробный дневной блок и график «план / факт». Дату можно выбрать календарём, стрелками или нажатием на день графика. Общие фильтры врача и периода этот блок не меняют. Личные нормы врачей не рассчитываются.

План берётся из поля «План месяца» окна «Годовой план…», факт — сумма количества услуг 001983 + 001984 данной ЖК в накопительной выгрузке. Факт из PDF и факт услуг не складываются. Для каждого нового месяца обновите дату плана и месячные планы в программе, затем загрузите выгрузку с 1-го числа.

Дневной ориентир = округлённый вверх остаток месячного плана на начало выбранного дня / вес оставшихся дней месяца × вес выбранного дня. Будни весят 1, суббота и воскресенье — по 0,5. Сегодняшнее выполнение уменьшает остаток до дневной нормы, но не сам ориентир этого дня. Внизу отдельно показан базовый равномерный темп. Праздники и графики смен не учитываются.

По умолчанию отображается последняя дата выгрузки, а не текущая дата компьютера. Дни после неё не заполняются нулями. При несовпадении месяца, неполной выгрузке с начала месяца или отсутствии ЖК показывается причина вместо расчёта. При нулевом плане или перевыполнении отрицательных остатков нет.

Новых Python-библиотек не требуется. JavaScript и анимация встроены в автономный HTML. Анимация заполнения — 240 мс; клавиатура и режим уменьшенного движения обновляют результат сразу.
